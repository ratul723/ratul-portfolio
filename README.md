# Radwanul Habib Ratul — Portfolio

A responsive personal portfolio built with React, Vite, Tailwind CSS, Framer Motion, and Lucide icons.

## Included
- Dark / light theme toggle (saved in local storage)
- Responsive navigation and page layout
- About, experience, skills, projects, education, and contact sections
- CV download (`public/Radwanul-Habib-Ratul-CV.pdf`)
- Motion effects and mobile-friendly layouts

## Run locally

Requirements: Node.js 18+ and npm.

```bash
npm install
npm run dev
```

Open the local URL printed by Vite (usually http://localhost:5173).

## Production build

```bash
npm run build
npm run preview
```

The production website is generated in `dist/`.

## Deploy to Vercel
1. Push this project to a GitHub repository.
2. Import the repository into Vercel.
3. Framework preset: Vite.
4. Build command: `npm run build`.
5. Output directory: `dist`.
6. Deploy.

## Before publishing
- Confirm that every project description accurately reflects your contribution.
- Add the real GitHub repository/demo URL to each project card when available.
- Confirm the CV PDF is the version you want public.
- The contact CTA uses `mailto:`; it opens the visitor's email app and does not submit to a backend.
- Personal home address, family details, date of birth, and references from the source CV are intentionally not published on the portfolio.
